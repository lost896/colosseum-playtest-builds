# Marble Colosseum playtest

Windows co-op playtest builds and automatic updates. Unreal Engine does not need to be installed to play.

## Install once

1. **[Download the auto-update launcher](https://github.com/lost896/colosseum-playtest-builds/releases/latest/download/Colosseum-AutoUpdate-Launcher.zip)**.
2. Extract the complete launcher folder. Keep `ColosseumLauncher.exe` and `launcher.json` together.
3. Open Steam and sign into your account, then open `ColosseumLauncher.exe`.
4. The launcher downloads the game on first use and checks for updates whenever you reopen it.

Close the game before updating. If downloading fails, you can play the installed version; **Previous version** restores the prior build. Both friends should open the launcher before joining so they have the same release.

## Play with a friend

Enter a contestant name and choose **Host Steam co-op**. Once inside the arena, press **F2 → Invite Steam friend**. Your friend should have the game open and accept your invite through Steam.

- WASD: move. Mouse: look. Space: jump. F2: contestant/session menu.
- Host: 1–5 change the floor layout; R flattens it; T enables the automatic cycle.

This development playtest uses Steam test App ID 480; Steam may display **Spacewar**. Use separate Steam accounts. Steam lobby creation and relay transport have been checked; a real invite between two PCs still needs playtesting.
